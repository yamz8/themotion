# Enjoy each opinion equally

An old terminal boots. The tube switches on as a line across the middle that opens into the screen. TERMINAL: ONLINE types itself on behind a block cursor, then BRANCH: 501. The binary rows either side of the mark print left to right, and the mark loads top to bottom in rows of blocks, like a picture coming down a slow line. OMARCHY types on a letter at a time, the tagline follows behind the cursor, and the dashed rule below fills in steps like a progress bar. There are no glows or flares: everything arrives in hard steps.

| Time | Beat |
|---|---|
| 0.05 | A line across the middle opens into the screen |
| 0.55 | TERMINAL: ONLINE types on; BRANCH: 501 follows |
| 0.9 | The data rows print left to right |
| 1.35 | The mark loads row by row |
| 2.4 | OMARCHY types on, a letter at a time |
| 3.1 | The tagline types on behind the cursor |
| 3.85 | The rule fills in steps |
| 5.0 | Still; the pattern blends into the exact wallpaper |

Everything that glows in this wallpaper is light on a dim field, so each layer is stored as the light it adds over the backdrop and drawn with `lighter`. The backdrop is never brighter than the wallpaper under a layer, so the layers add back to the exact picture.
