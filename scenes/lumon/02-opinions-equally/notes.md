# Enjoy each opinion equally

The terminal warms up like a picture tube: a line grows across the middle and opens into the screen. TERMINAL: ONLINE types itself on behind a block cursor, BRANCH: types on and its number rolls in digit by digit. The binary rows either side of the mark flicker on outward from the middle, the mark resolves cell by cell and sends out a square pulse, and OMARCHY opens letter by letter from its centre line. The tagline's letters light up in no particular order, each one getting its turn, and the dashed rule below fills like a progress bar and flashes once.

| Time | Beat |
|---|---|
| 0.05 | A line across the middle opens into the screen |
| 0.55 | TERMINAL: ONLINE types on; BRANCH: follows |
| 1.0 | 501 rolls in, digit by digit |
| 0.9 | The data rows flicker on from the middle outward |
| 1.35 | The mark resolves cell by cell |

| 2.4 | OMARCHY opens from its centre line, middle letters first |
| 3.1 | The tagline's letters light in a shuffled order |
| 3.85 | The rule fills, then flashes |
| 5.0 | Still; the pattern blends into the exact wallpaper |

Everything that glows in this wallpaper is light on a dim field, so each layer is stored as the light it adds over the backdrop and drawn with `lighter`. The backdrop is never brighter than the wallpaper under a layer, so the layers add back to the exact picture.
